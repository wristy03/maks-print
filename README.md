# Maks Print — новый сайт (прототип)

Статичный сайт-витрина для https://maksprint.it на итальянском. Без сборки и без зависимостей.

## Запуск

```bash
node scripts/serve.mjs
```

Открыть http://localhost:5173

## Обновить каталог

Товары, цены, цвета, размеры и варианты подтягиваются из WooCommerce Store API maksprint.it:

```bash
node scripts/sync-catalog.mjs
```

Скрипт перезаписывает `assets/js/catalog.js`. Руками этот файл не правят.

## Структура

- `index.html` — разметка всех секций
- `assets/css/style.css` — стили (адаптив: 960px и 640px)
- `assets/js/app.js` — каталог, карточка товара, заказ, галерея, форма запроса цены
- `assets/js/catalog.js` — данные каталога (генерируется)
- `scripts/sync-catalog.mjs` — синхронизация каталога
- `scripts/serve.mjs` — локальный сервер для превью

## Как оформляется заказ

Корзина хранится в `localStorage` браузера. Из неё можно:

1. **WhatsApp** — готовое сообщение со списком, вариантами, персонализацией и суммой на +39 328 898 1569.
2. **Email** — то же письмом на infomaksprint@gmail.com.
3. **Оплатить онлайн** — каждая позиция добавляется в настоящую корзину maksprint.it по ссылке
   `/cart/?add-to-cart=<id>&variation_id=<id>&attribute_pa_colore=…&attribute_pa_taglia=…&quantity=…`,
   затем «Vai alla cassa» открывает `/checkout/`. Оплата проходит на текущем WooCommerce.

## Удобство

- **Кнопка «Назад»** закрывает окно товара, корзину и просмотр фото, а не уводит с сайта.
- **Ссылки на товар:** `#p/<slug>` и `#p/<slug>/<colore>` (кнопка «Condividi» в карточке копирует ссылку с выбранным цветом).
- **Несколько размеров подряд:** после «Aggiungi all’ordine» карточка остаётся открытой, размер сбрасывается, цвет остаётся.
- **Клавиатура:** цвета и размеры переключаются стрелками, `/` ставит курсор в поиск, `Esc` закрывает окна.
- **Поиск** не учитывает регистр и диакритику и знает разговорные слова: «maglietta», «giubbotto», «tuta», «bambino».
- **Корзина** при каждой загрузке сверяет цены и варианты с текущим каталогом.

## Ограничения

- Фото, видео и логотип загружаются напрямую с maksprint.it. Если старый сайт выключат, их нужно перенести.
- Текст персонализации не передаётся в корзину WooCommerce: при онлайн-оплате его пишут в заметках к заказу.
- Формы не имеют сервера: они открывают WhatsApp или почтовый клиент.
